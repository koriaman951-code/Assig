# Power BI Interactive Dashboard Assignment

An interactive Business Intelligence (BI) dashboard built in **Microsoft Power BI Desktop** (`assignment.pbix`) to transform raw data into visual insights, KPI summaries, and interactive performance reports.

---

## Project Overview
This project demonstrates end-to-end data modeling, DAX metric creation, and interactive report design in Power BI. Users can dynamically filter metrics across categories, time periods, and segments to explore trends and key business drivers.

---

## Key Features
* **Data Cleaning & Transformation:** Shaped and standardized raw records using **Power Query Editor** (data type formatting, null handling, and column transformations).
* **Data Modeling:** Structured clean relationships across tables for accurate cross-filtering.
* **DAX Calculations:** Created custom calculated measures and KPI cards to track totals, averages, and comparative performance.
* **Interactive Visuals & Slicers:** Designed dynamic bar/column charts, trend lines, tables, and slicers for multi-dimensional drill-down analysis.
